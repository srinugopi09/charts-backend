   - **google-adk `DatabaseSessionService`**: Built-in PostgreSQL session persistence (no custom implementation needed)
   - **ag-ui-adk `ADKAgent`**: Accepts `session_service=` parameter for custom session backends; cannot use both `user_id` and `user_id_extractor` simultaneously
   - **PreciseTimestamp timezone bug**: google-adk uses `DateTime` (no timezone) but inserts timezone-aware datetimes; asyncpg rejects the mismatch. Requires monkey-patching.
   - **AG-UI Protocol**: SSE event stream with typed events (TEXT_MESSAGE_*, TOOL_CALL_*, STATE_DELTA, CUSTOM, RUN_STARTED/FINISHED)
   - **`/agents/state` endpoint**: Provided by ag-ui-adk for session recovery; requires `appName` and `userId` in request body when using `user_id_extractor`
   - **Thread ownership**: Server-side thread records tied to authenticated user, not client-side localStorage
   - **`extract_state_from_request` + `user_id_extractor` pattern**: Injects user ID from HTTP header into AG-UI state, then reads it back for ADK session scoping
   - **`_INTERNAL_TABLES` filtering**: Hides ADK and app tables (sessions, events, app_states, user_states, adk_internal_metadata, threads) from the agent's SQL tools
   - **Angular frontend architecture**: Signal-based services (ChatStateService, SharedStateService, A2UIEventService), @ag-ui/client HttpAgent with auto-generated threadId/runId (uuid v4)
